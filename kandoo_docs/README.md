# Kandoo vault

This window holds the method. Start with /start. Use /pick-job for an existing method or /create-job → /mission → /workflow for a custom one. /apply builds an independent project template. /new-project opens the handoff to the work window. /inspect reads evidence from a registered project. /new-version collects proposed method changes. /migrate updates only explicitly chosen projects. /report-moom prepares a private note for manual delivery to the instructor.
