# Kandoo vault

/start → /job → /mission → /workflow → /topology → /shared-code → /floating-commands → /testing → /apply → /new-project. Open the project in a separate session. Run real projects, use /inspect for method notes and clear defects, and /new-version for planned revisions. Use /migrate to adopt revisions in existing projects. A Kandoo matures as repeated deliveries verify its method.

Each step uses numbered analysis rounds before its living specification is written. Save answers and comments, then say done or نوشتم. A clear repeatable defect can be patched and verified by /inspect in one invocation.
