# /pick-job

Read method status first. If already configured, show the applied version and route changes to /new-version. Finish /start first if language setup is pending. If the identifier is missing or unknown, list the local catalog and ask which one the participant means.

Verify the selected starter's mission, workflow, complete steps and references. Check every command against command-names.md and installed host catalogs. Record the chosen ID in status before copying. Install mission.md, workflow.md, steps/ and references/ from that single registry entry under kandoo_docs/living/. Compare bytes with the starter; on retry reuse matching files and reconcile any unexpected edits before writing. Keep the registry and all seven choices. Record the exact selection and skip custom definition. Execute /apply as the final part of picking. Once verification succeeds, hand off to /new-project.
