# /job

Read status and resume the open dossier after /start. Read the participant’s original words, existing material and sample outputs. If the normalized input SHA256 matches Job guide SHA256 in status or the file is empty, ask for the routine in chat or the input file. For video samples inspect size, codec, dimensions, duration, sound and representative frames. For documents inspect structure and deliverables. Record filenames, hashes, findings and rights to reuse assets in the dossier. Keep large originals in ignored samples/. Keep project-one facts separate for its interpretation.

Determine whether successive projects serve one domain or differ each time. For a domain-bound method record authoritative sources, reusable facts, visual invariants and approved assets. After convergence put reusable context in living/context/ and assets in template/. Agree whether to copy, refresh at version review, or live-link a specific source from projects. Verify access from the consuming location.

Consult registry/ for possible starting patterns. Record why a pattern fits and what changes. Review the recurring task, present manual process, automation requests, exclusions and first-project example. Keep deferred method features in living/roadmap.md. A starter always goes through the complete setup. Start with numbered analysis of the input and samples. After convergence save the agreed brief and context, update the roadmap, and offer /mission.
