# /iterate

Read project status, accepted work, roadmap and the requested change. If the goal is missing ask for it. Resume an already open matching iteration; otherwise preserve the current delivery and open the next numeric version in docs/versions/. If another iteration is open, finish or explicitly supersede it first. Capture the requested change in the new 00-iteration-input.md and set its full path as Current input in status. Record affected stages, dependencies, evidence that can be reused and reasons for skipped stages. Maintain the local idea/decisions, review the impact, then start the first affected step. A method defect discovered here belongs in a separate method note.
