# /issue

Ask for the symptom when missing. Capture expected versus observed behavior and affected revision in the next numbered issue record in docs/versions/VERSION/. Reproduce safely with local evidence, identify the source, repair only affected work and check related outputs for regression. Preserve prior deliveries, user edits and authorization. Record evidence and the restored next step in local status. For procedure friction append a method note with the affected step.

At closure record the comparison to the installed procedure, origin (project, reusable method, or undetermined), and retest result. For a repeatable method defect write or link one sanitized docs/method-notes/ entry. For uncertain origin record the evidence still needed.
