# Locate an entity's version documents and current result

Resolve the target from context or ask in chat if unknown. Read workspace.json for the
selected version/docs and list that entity's existing version.json records numerically.
Link current input, review rounds, living notes and actual artifact. New histories use
versions/VMAJOR/VMAJOR.MINOR/ with patch folders underneath. Moom, Job and Project
numbers are independent; review-round numbers are not release numbers. Do not rename
existing history or invent a release from metadata alone.
