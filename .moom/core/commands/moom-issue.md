# Diagnose and correct a defect with its owning entity

Resolve Project, Job, shared workspace or Moom from the request. If unknown, ask
in chat/harness before any question file. Ask which result is affected, not for the
cause. If neither party can locate the target, use issue --target intake TITLE,
then diagnose and move/link the record to its owner without losing answers.

Record defects with issue --target project|job|workspace|moom TITLE [--project ID].
Use the owning entity's current minor/patch history. A Job issue must work before any
Project exists. Moom reports go in workspace feedback for upstream. Do not duplicate
competing issue records; link related result, helper, Job or engine corrections.

Read the actual requested source, diagnose before rewriting, fix the result and improve
the reusable procedure/helper when applicable. Verify the correction and record the
Job revision; a preference for one Project is not automatically a general rule.
