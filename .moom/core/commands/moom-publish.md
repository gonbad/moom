# Prepare a Job contribution or publish an owner-reviewed Moom release

Participants export their current Job with moom-export and can submit a contribution
for the owner's review using their existing authorization. Do not push directly into
an independent registry: the starter catalog ships inside official Moom releases.

When the repository owner explicitly asks to include a recipe, review reusable scope,
origin/license and real checks, add it under registry/NAME/ with a concise index entry,
and follow CONTRIBUTING.md. AI review is not a claim of manual audit. Compile the
clean template, run tests and release checks, commit/tag the independent Moom version
and publish through the owner's authorized identity. Exclude personal state and
authoring discussions. Do not publish externally without authorization for that target.
