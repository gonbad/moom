# Export a reusable Job for another workspace or contribution

Read the current job/NAME/SKILL.md, origin and license. Use export-job --output PATH
to package only allowlisted reusable instructions, helpers and assets, with identity,
independent version and hashes. Keep Project inputs, workspace profile, reviews,
credentials, generated outputs and installed environments out of the package.
Inspect the archive. The recipient adapts and checks it as a candidate; the original
owner's artifact acceptance or audit status does not transfer with the files.
