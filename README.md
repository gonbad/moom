# Moom

Moom version: 0.12.0

Use this template to create a personal repository, or extract the kit into its own folder. Open that folder in your AI host and open `kandoo_docs/` as the method vault in Obsidian. Run `/start` (Codex CLI: `$start`; Antigravity: select the skill). Describe the task you repeat. /job can adapt an internal example. Review mission, workflow, topology, shared code, floating commands and testing before /apply. Every workflow step starts with a numbered analysis. Only the participant edits it after handoff. Once the analysis rounds converge, the assistant writes the living result and the participant chooses when to start the next step. The assistant operates Git and the bundled Python 3.9+ helper.

Once the template is ready, describe an output to `/new-project`. Open the resulting project directory in a second AI session and its `docs/` in a separate Obsidian window. Write your idea in the editable job-specific guide and run `/idea`. The topology records where the project and any shared dependencies live.

See the [method vault](kandoo_docs/README.md) and [prepared starters](registry/README.md).
