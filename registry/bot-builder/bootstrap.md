# Project intake for bot-builder

Use `first-bot` as the provisional slug when the participant has supplied no topic.
Use the reserved numeric ID for this Project. Keep any supplied title and material.

In the chat language, point to these prepared locations with the actual Project ID.

- `docs/projects/ID/versions/0.1/00-idea-input.md` — Describe a task the bot should help someone finish, or share a conversation you want to improve.
- `docs/projects/ID/versions/0.1/sources/notes.md` — optional material such as sample conversations, menu wording or workflow notes.
- `projects/ID/existing/` — create this folder before offering it for an existing bot project or exported conversation examples.

If useful material is already present, link it and acknowledge where it was saved.
After saving, use the first command in the installed Job. For a newly installed
Job, close and reopen the workspace in the current host first.
