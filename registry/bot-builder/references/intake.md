# Project intake for bot-builder

- `docs/versions/0.1/00-user-idea-input.md` — Describe a task the bot should help someone finish, or share a conversation you want to improve.
- `docs/versions/0.1/sources/notes.md` — optional material such as sample conversations, menu wording or workflow notes.
- `./existing/` — create this folder before offering it for an existing bot project or exported conversation examples.

The participant writes the idea in their own words before /idea. Interpretations and examples belong in the separate interpretation file.
