# /job-idea

Read `AGENTS.md`, the four `docs/constitution/` documents and `docs/kandoo/living/profile.md`,
`job.md`, `server.md` and `status.md`. Resolve the active Project `ID` and `VERSION` from
status; all paths are workspace-root paths. Read only the installed references
`docs/kandoo/living/references/workflow.md` and `distribution.md` plus
the selected-version input recorded in `docs/projects/ID/living/status.md` and submitted rounds in that version.
Preserve earlier outputs and authorization.

Identify the intended reader, reader problem, desired outcome, actual actor/action
sequence, format, language and delivery route (local private draft vs authorized public
post). Inventory supplied sources and creator corrections in order; distinguish primary
facts, quotations and inference. Inspect any existing assets under `projects/ID/` before
replacing anything. Bank out-of-scope or future post ideas in
`docs/projects/ID/living/roadmap.md`.

Always write and maintain `docs/projects/ID/living/idea.md` with scope, source contract,
exclusions, explicit public source folder (`projects/ID/src/` or `site/`), private input
boundaries, output format and acceptance examples. New posts remain private drafts unless
publication is deliberately selected in `docs/projects/ID/living/publication.md`; never
require `project.json`, an engine or a server to start writing. Put open editorial or
delivery questions in `docs/projects/ID/versions/VERSION/NN-questions.md`. Once any open
question round is submitted (Confirmed or Delegated/Provisional), hand off directly to
`/job-brief`; a technical check or delegated blank never certifies source fidelity.

Apply the file-review/certainty protocol on `.md` files inside `docs/` and assess updates
to the Job, shared Kandoo, active Project and write-only creator feedback. Persist what
changed, current evidence, pending items and next action in `docs/projects/ID/living/status.md`
and mirror `docs/kandoo/living/status.md`. Finish every reply with the current Job's full ordered
steps localized and one exact next action (`/job-brief` or the pending `.md` question file).
