# blog-publisher workflow

Server mode: shared

At /deploy, use the shared connection instructions copied into this project. Allow private/local delivery. For authorized hosting, inspect the target, allocate the route and record its verification here.

| Command | Stage | فارسی | Exit or condition |
| --- | --- | --- | --- |
| `/idea` | Idea and scope | ایده و دامنه | Scope, reader problem and source boundaries resolved |
| `/brief` | Editorial brief | بریف و زاویه دید | Audience, thesis, angle and constraints resolved |
| `/story` | Story structure | ساختار روایت و رئوس | Ordered section hierarchy, actor sequence and evidence map resolved |
| `/content` | Content authoring | نگارش متن و محتوا | Complete narrative written with claim-to-source traceability |
| `/layout` | Layout and styling | صفحه‌آرایی و گرافیک | Typography, RTL/LTR isolation and layout built on real text |
| `/build` | Build and verify | ساخت و بررسی | Web build, links, hashes and browser behavior verified |
| `/deploy` | Publish | انتشار | Public origin/aliases verified or explicit hosting deferral recorded |

For the initial version follow these stages in order. Read each installed procedure for its inputs, outputs and exit evidence. Review only affected stages and prerequisites during later iterations.
