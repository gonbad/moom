# Flexible presentation output

Choose orientation, dimensions, format, interaction and delivery with the participant.
Landscape 16:9 is an example, never a constraint. Portrait, print, interactive HTML,
complex visualizations and other formats are valid; adapt the method accordingly.
Do not force all slides into a fixed JSON schema or simple text template.

Generate a suitable artifact under the Project only when needed. For HTML, author
layouts directly with local assets, useful keyboard/touch navigation, readable mobile
behavior, correct RTL/LTR isolation and accessible controls. Test the actual selected
features (notes, overview, browser navigation, fullscreen, charts) and screen states.
For offline use verify from file:// with networking disabled; package all runtime
dependencies and license notices. Private source/input stays outside the public asset
set. Visual/source fidelity, interaction checks and the speaker's acceptance are separate.
