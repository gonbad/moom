# Project intake for presentation-maker

- `docs/versions/0.1/00-user-idea-input.md` — Describe the talk you want to give, or what you want to change in an existing talk.
- `docs/versions/0.1/sources/notes.md` — optional material such as speaker notes, an outline or source links.
- `./existing/` — create this folder before offering it for an existing slide deck, diagrams or images.

The participant writes the idea in their own words before /idea. Interpretations and examples belong in the separate interpretation file.
