# Presentation maker

Develop a speaker-led talk from the speaker's idea, evidence and existing material. Deliver an editable source and a transferable, self-contained folder that opens at `index.html` offline. Default to horizontal slides. Derive length from the narrative unless the speaker supplies a time limit. Offer a short rehearsal route for a long deck.

Every content slide, chapter milestone and interactive exercise has a stable identity. The audience sees the material intended for projection; the speaker can see private notes in a separate window. Use the project’s language, layout direction and theme. Choose technology around actual interactions and offline delivery. ZIP, print, alternate formats and hosting follow the project’s delivery choice.
