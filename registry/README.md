# Starter catalog

Pick one starter by identifier for its exact mission, workflow, procedures and references. Use /create-job to adapt or design a method. The catalog remains available after setup.

- [film-maker](film-maker/mission.md): Guide a first-time filmmaker from reviewed prose and voice choices to a scene script with camera positions. Review prompts by sequence, record by speaking turn, jointly performed scene or continuous solo narration, then build the storyboard and deliver a verified MP4.
- [motion-maker](motion-maker/mission.md): Create reviewed visual assets and local HTML motion, then explicitly requested silent video and optional dubbing.
- [presentation-maker](presentation-maker/mission.md): Create speaker-led, horizontal presentations with left/right navigation and downloadable offline delivery by default; hosting is optional.
- [blog-publisher](blog-publisher/mission.md): Publish self-contained articles, guides and papers for independent readers, with online URLs and vertical scrolling by default.
- [web-app-builder](web-app-builder/mission.md): Build independent web products from reviewed requirements and approved external designs, then test and deploy them with HTTPS.
- [bot-builder](bot-builder/mission.md): Build deterministic Telegram, Bale or Rubika menu/button/dialog bots, with optional narrow AI helpers and owner-selected payment policies.
- [agentic-chatbot](agentic-chatbot/mission.md): Build model-directed conversational tools only when a simpler bot is insufficient, with caller-scoped authority, explicit policies and enforced budgets.
