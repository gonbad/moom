# Flexible starter catalog

Use a matching starter, adapt the nearest one **only as an initial base**, or author a
new Job. These paths are equal during custom definition. `/pick-job IDENTIFIER` instead
copies the selected prepared starter exactly, with no method-definition questions. Desired format, orientation, style, output and step
changes always take precedence over examples. Evolve the method during real Projects.
All procedures are Markdown; no scripts, manifests, assets or source-repository origin
metadata are required. Each starter has a `bootstrap.md` intake guide and reusable English and Persian idea pages in `project-input/`.
Install its method, bootstrap, references and both intake pages locally in the
Kandoo before deleting this entire bootstrap catalog.

- [film-maker](film-maker/job.md): Guide a first-time filmmaker from reviewed prose and voice choices to a scene script with camera positions. Review prompts by sequence, record by speaking turn, jointly performed scene or continuous solo narration, then build the storyboard and deliver a verified MP4.
- [motion-maker](motion-maker/job.md): Create reviewed visual assets and local HTML motion, then explicitly requested silent video and optional dubbing.
- [presentation-maker](presentation-maker/job.md): Create speaker-led, horizontal presentations with left/right navigation and downloadable offline delivery by default; hosting is optional.
- [blog-publisher](blog-publisher/job.md): Publish self-contained articles, guides and papers for independent readers, with online URLs and vertical scrolling by default.
- [web-app-builder](web-app-builder/job.md): Build independent web products from reviewed requirements and approved external designs, then test and deploy them with HTTPS.
- [bot-builder](bot-builder/job.md): Build deterministic Telegram, Bale or Rubika menu/button/dialog bots, with optional narrow AI helpers and owner-selected payment policies.
- [agentic-chatbot](agentic-chatbot/job.md): Build model-directed conversational tools only when a simpler bot is insufficient, with caller-scoped authority, explicit policies and enforced budgets.

`/start` enumerates the actual local entries and supplies their host-appropriate
selection commands. Only existing complete starters are offered. Choose one current
Job per Kandoo; use independent Kandoos for different prepared Jobs. New Projects in
a configured Kandoo reuse its evolving Job, without restoring this catalog.
