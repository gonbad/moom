# Flexible starter catalog

Use a matching starter, adapt the nearest one **only as an initial base**, or author a
new Job. These paths are equal. Desired format, orientation, style, output and step
changes always take precedence over examples. Evolve the method during real Projects.
All procedures are Markdown; no scripts, manifests, assets or source-repository origin
metadata are required. Install/adapt every needed command and reference into the
Kandoo before deleting this entire bootstrap catalog.

- [presentation-maker](presentation-maker/job.md): Create presentations in the participant’s chosen orientation, format and style, including rich interactive or offline outputs.
- [blog-publisher](blog-publisher/job.md): Create independently designed articles, guides, papers or presentations with verified offline packages and optional shared hosting.
- [web-app-builder](web-app-builder/job.md): Build independent web products from reviewed requirements and approved external designs, then test and deploy them with HTTPS.
- [bot-builder](bot-builder/job.md): Build deterministic Telegram, Bale or Rubika menu/button/dialog bots, with optional narrow AI helpers and owner-selected payment policies.
- [agentic-chatbot](agentic-chatbot/job.md): Build model-directed conversational tools only when a simpler bot is insufficient, with caller-scoped authority, explicit policies and enforced budgets.
