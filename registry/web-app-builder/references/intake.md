# Project intake for web-app-builder

- `docs/versions/0.1/00-user-idea-input.md` — Describe what you want someone to do in the app, or what you want to change in the existing product.
- `docs/versions/0.1/sources/notes.md` — optional material such as requirements, user notes or a link to the current site.
- `./existing/` — create this folder before offering it for an existing app, source bundle or screenshots.

The participant writes the idea in their own words before /idea. Interpretations and examples belong in the separate interpretation file.
