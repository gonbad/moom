# Project intake for web-app-builder

Use `first-app` as the provisional slug when the participant has supplied no topic.
Use the reserved numeric ID for this Project. Keep any supplied title and material.

In the chat language, point to these prepared locations with the actual Project ID.

- `docs/projects/ID/versions/0.1/00-idea-input.md` — Describe what you want someone to do in the app, or what you want to change in the existing product.
- `docs/projects/ID/versions/0.1/sources/notes.md` — optional material such as requirements, user notes or a link to the current site.
- `projects/ID/existing/` — create this folder before offering it for an existing app, source bundle or screenshots.

If useful material is already present, link it and acknowledge where it was saved.
After saving, use the first command in the installed Job. For a newly installed
Job, close and reopen the workspace in the current host first.
