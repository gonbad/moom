# Project intake for agentic-chatbot

Use `first-assistant` as the provisional slug when the participant has supplied no topic.
Use the reserved numeric ID for this Project. Keep any supplied title and material.

In the chat language, point to these prepared locations with the actual Project ID.

- `docs/projects/ID/versions/0.1/00-idea-input.md` — Describe one real request you want the assistant to handle, or point to an existing workflow.
- `docs/projects/ID/versions/0.1/sources/notes.md` — optional material such as example requests, service documentation or desired outcomes.
- `projects/ID/existing/` — create this folder before offering it for an existing assistant project or sample input files.

If useful material is already present, link it and acknowledge where it was saved.
After saving, use the first command in the installed Job. For a newly installed
Job, close and reopen the workspace in the current host first.
