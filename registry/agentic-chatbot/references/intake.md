# Project intake for agentic-chatbot

- `docs/versions/0.1/00-user-idea-input.md` — Describe one real request you want the assistant to handle, or point to an existing workflow.
- `docs/versions/0.1/sources/notes.md` — optional material such as example requests, service documentation or desired outcomes.
- `./existing/` — create this folder before offering it for an existing assistant project or sample input files.

The participant writes the idea in their own words before /idea. Interpretations and examples belong in the separate interpretation file.
