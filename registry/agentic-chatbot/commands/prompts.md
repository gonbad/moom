# Author the actual runtime prompts

Write the concrete system/persona instructions, facts and relevant example dialogues
under SOURCE/prompts/. Link their reviewed manifest from LIVING/prompts.md. Include
structured outcome interpretation, tool-use limits, refusal/correction and selected
soft-confirmation behavior without claiming prompt text enforces hard authorization.
Never include real tokens, sensitive raw data or another caller's context. Review
representative conversations with the owner before the implementation handoff.
