# /idea

Read the project constitution and current status. Use the following references from `docs/references/`: `workflow.md`, `quality.md`, `intake.md`.

Read the recorded Current input, existing material inventory and submitted rounds.
Reuse supplied facts before asking anything. Resolve audience, communication goal,
main claim, language, platform/aspect ratio, provisional duration and desired delivery
(HTML, silent video or voiced video). Ask only choices that affect the result; never
assume an event, character, price, style or registration window from the starter.

Maintain `docs/living/idea.md`, `sources.md` and `roadmap.md`. Track
source evidence, confirmed facts and delegated assumptions separately. For time-sensitive
copy record intended publication time/timezone and the relevant event/registration facts;
leave missing facts pending. Do not ask for a server or voice API credentials.
Once review closes, hand off to `/outline`.
