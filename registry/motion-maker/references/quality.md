# Motion acceptance and delivery evidence

| Gate | Required evidence | Defect to exercise |
| --- | --- | --- |
| Story and sources | Accepted narrative, scene contract and claim provenance | Unsupported event fact or narration pasted onto the screen |
| Individual visuals | Explicit reviewed revision, all needed poses/states | Unwanted feature, missing expression or unusable raster layers |
| Gallery | Source hashes/mapping and state/transition walkthrough | Arm action rotates whole body; CSS/ID collision changes another asset |
| Representative scene | Side-by-side gallery/source comparison at matched times | Correct asset but incorrect wrapper transform or scaling |
| Full HTML preview | Complete walkthrough, repeatable seek and acceptance identity | Clock drift, jitter, clipped Persian text, missed cut/hold |
| Silent render | Actual media probe, sampled-frame comparison and full viewing | Blank fonts, controls captured, truncated or wrong-length encode |
| Dubbing | Listening/alignment check on actual final file | Bad pronunciation, clipping, drift, stale subtitles |
| Public delivery | Exact artifact identity, accepted copy and live/local receipt | Stale registration CTA, placeholder URL or internal chat in caption |

Maintain each gate's technical, source-fidelity and human-acceptance evidence separately.
An accepted gallery does not accept a full movie; a passing media probe does not prove
visual quality. Use reviewable local URLs with Markdown instructions in the version
dossier. If a required viewing/listening tool is unavailable, record the check pending
instead of simulating evidence. Reuse prior approval for unchanged content, while
identifying the exact changed artifact that needs review.

At export, inspect the clean capture surface, audio, subtitle file/track, caption and
thumbnail separately. Keep internal comments, rejected decisions, setup instructions,
source paths and recording controls out of audience-facing output. Check factual claims
and calls to action at the intended publication date/time and timezone: “register now”
needs an open registration window and a working destination. Do not infer a new event's
price/window/URL from another Project. Resolve placeholders before final delivery.

Preserve editable sources and previous accepted exports. Record output paths/hashes,
duration/dimensions, source baseline, review results, known limits and delivery mode in
`docs/living/delivery.md`. Preview and delivery are local by default. Public upload needs
the already-authorized target or a specific remaining authorization; do not ask again
when authorization already exists. No hosting, server or automatic publishing is part
of this starter's default pipeline.
