# Project intake for film-maker

Use `first-film` as the provisional slug when the participant has supplied no topic.
Use the reserved numeric ID for this Project. Keep any supplied title and material.

In the chat language, point to these prepared locations with the actual Project ID.

- `docs/projects/ID/versions/0.1/00-idea-input.md` — Tell the story in your own words. A voice transcription or unfinished scene is enough to begin.
- `docs/projects/ID/versions/0.1/sources/notes.md` — optional material such as a draft script, notes about the characters or a link to a reference film.
- `projects/ID/existing/` — create this folder before offering it for a clip, drawing, character reference or audio take.

If useful material is already present, link it and acknowledge where it was saved.
After saving, use the first command in the installed Job. For a newly installed
Job, close and reopen the workspace in the current host first.
