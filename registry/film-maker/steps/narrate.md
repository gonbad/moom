# /narrate

Read the project constitution and current status. Use the following references from `docs/references/`: `production.md`.

Use the sequence and selected prompt revision from prompt review. Offer the workshop TTS link when supplied, another TTS reader, or the participant’s own recording. For separately performed voices or TTS, record each uninterrupted speaking turn as its own take. When actors perform a scene together, retain the full scene take and mark the cues for its individual turns. When one narrator carries a sequence, retain the continuous sequence take. Reuse the selected take or excerpt for scripted playback. Keep a voice reference per speaker.

Read the selected prompt sheet for the recording folder, filenames and style instructions. Inspect the folder before asking for audio. Match new and earlier takes to the appropriate prompt revision by ID or the participant’s mapping. Listen for the named performance cues and flag only missing or ambiguous takes.

Import the supplied audio, retaining the original and earlier takes. Accept WAV, MP3, OGG or another format the local tools can decode. Check playback and measure duration. Link each take to its speaker or cast, the turns and shots it covers, its sequence and the exact prompt revision in the Project notes. If the participant changed the text in the recording tool, reconcile the spoken words with docs/living/script.md and record the actual wording alongside the selected prompt. Ask “Do the words and delivery sound right?” A change to the words or directions returns to prompt review for this sequence. A performance-only retry can reuse the selected prompt. Save the chosen take and its duration for storyboarding, then continue with the next outstanding prompt.
