# film-maker workflow

Server mode: none

Work locally through delivery. This workflow has no infrastructure intake.

| Command | Stage | فارسی | Exit or condition |
| --- | --- | --- | --- |
| `/idea` | Idea | ایده | edit the whole story in prose, confirm who speaks and record the title. |
| `/story` | Story | داستان | adapt the accepted prose into scenes with camera positions and a shot ID for each speaking turn. |
| `/narration-prompt` | Narration prompt | راهنمای صدا | review one document per sequence, with copyable style and speech for each performance and a folder for the takes. |
| `/narrate` | Narrate | ضبط | record separate voices by uninterrupted speaking turn, actors performing together by scene, and continuous solo narration by sequence. |
| `/storyboard` | Storyboard | استوری‌بورد | time the pictures to the chosen performance. |
| `/visuals` | Visuals | تصاویر | establish the cast and finish one telling shot. |
| `/animate` | Animate | پویانمایی | finish the action, then mix sound for each sequence. |
| `/render` | Render | خروجی | assemble, inspect and deliver the film. |

For the initial version follow these stages in order. Read each installed procedure for its inputs, outputs and exit evidence. Review only affected stages and prerequisites during later iterations.

References in `docs/references/`: `intake.md`, `production.md`.
