# /narrate

Read AGENTS.md, the four documents in docs/constitution/, the installed profile, Job and status in docs/kandoo/living/, and its references/production.md. Resolve the selected Project, open version, current input and submitted reviews. Work under projects/ID/ for media and docs/projects/ID/ for living notes and versioned Markdown reviews.

Use the sequence and selected prompt revision from prompt review. Offer the workshop TTS link when supplied, another TTS reader, or the participant’s own recording. Give them the reviewed block for a single continuous, voice-only take. Keep a short reference from the first chosen take for later sequences.

Import the supplied audio, retaining the original and earlier takes. Accept WAV, MP3, OGG or another format the local tools can decode. Check playback and measure duration. Link the take to its sequence and prompt revision in the Project notes. If the participant changed the text in the recording tool, reconcile the spoken words with living/script.md and record the actual wording alongside the selected prompt. Ask “Do the words and delivery sound right?” A change to the words or directions returns to prompt review for this sequence. A performance-only retry can reuse the selected prompt. Save the chosen take and its duration for storyboarding, then offer the next sequence’s prompt.

Record evidence, pending review and next action in Project and shared status. Apply the four-domain check and show the localized pipeline. Keep human acceptance separate from technical checks.
