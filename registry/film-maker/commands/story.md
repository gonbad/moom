# /story

For initial intake follow the workflow constitution’s “Read the first Project input”
section and the installed `docs/kandoo/living/bootstrap.md`. If there is only template
text, invite the participant to describe their idea in their own words and wait.

Read AGENTS.md, the four documents in docs/constitution/, the installed profile, Job and status in docs/kandoo/living/, and its references/production.md. Resolve the selected Project, open version, current input and submitted reviews. Work under projects/ID/ for media and docs/projects/ID/ for living notes and versioned Markdown reviews.

Use the supplied premise, draft and materials first. Carry a stated running time straight into the story plan. Respond to a concrete scene or dramatic choice. If the intended viewer is still ambiguous and changes the telling, ask one question grounded in the premise. Offer one motivated ending if needed. Choose language, aspect ratio, delivery and scope here. Save the premise in living/idea.md and the spoken lines, actions and sequence goals in living/script.md. Read back the script in an appropriate voice or present it for a read-through. Ask whether it feels like their story. Record the reviewed revision before expanding the shot list.

Record evidence, pending review and next action in Project and shared status. Apply the four-domain check and show the localized pipeline. Keep human acceptance separate from technical checks.
