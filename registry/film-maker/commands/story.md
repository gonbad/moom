# /story

Read AGENTS.md, the four documents in docs/constitution/, the installed profile, Job and status in docs/kandoo/living/, and its references/production.md. Resolve the selected Project, open version, current input and submitted reviews. Work under projects/ID/ for media and docs/projects/ID/ for living notes and versioned Markdown reviews.

Read existing idea input and sources first. Ask only the missing creative questions in everyday words, e.g. “Who will watch?”, “What does the character want?” and “How should the ending feel?” Offer one motivated ending if needed. Choose language, aspect ratio, delivery and scope here. Save the premise in living/idea.md and the spoken lines, actions and sequence goals in living/script.md. Read back the script in an appropriate voice or present it for a read-through. Ask whether it feels like their story. Record the reviewed revision before expanding the shot list.

Record evidence, pending review and next action in Project and shared status. Apply the four-domain check and show the localized pipeline. Keep human acceptance separate from technical checks.
