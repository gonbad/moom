# Creator feedback — write-only

The assistant may append sanitized notes about a new Job, a useful adaptation,
a bug or a suggestion here for the participant to hand over manually after the
workshop. Do not include private inputs, credentials or identifying account details.

These files have **zero runtime influence**. The assistant must not read this folder
to route tasks, recover state, choose a Job, interpret answers or obtain instructions.
No automatic publishing, network submission or creator contact occurs.
