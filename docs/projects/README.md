# Independent Project dossiers

The first Project is created and selected automatically when the Job is installed.
Use `kandoo-new-project` for later instances and `kandoo-switch` to resume another.

Each `ID` has `living/` and `versions/0.1/00-idea-input.md` here, plus root
`projects/ID/` for real inputs, source, design, evidence and output as the Job needs.
`living/status.md` retains selected version, Job revision, ordered step states,
pending review and one next action; `living/idea.md` retains current understood scope.
Never reuse another Project's input, private state, deployment ports or output by
accident. Shared server details belong to Kandoo unless this Project overrides them.
